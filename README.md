# Painel da Vó

Página estática (GitHub Pages) com humor, remédios, água, pressão, glicose e sono.
Os dados (`dados.enc.json`) são gravados pela skill Alexa **criptografados** (AES-256-GCM, chave derivada da senha com PBKDF2).
Sem a senha, o arquivo é ilegível. Veja a demonstração com dados de exemplo em `?demo`.
